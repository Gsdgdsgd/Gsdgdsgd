# 像素机甲对战小游戏实施计划

## Context

当前工作区只有默认 README，没有现成应用、依赖或素材。目标是交付一个无需安装、可直接在浏览器运行的双人同键盘像素机甲对战 Demo，同时覆盖玩法设计、核心代码结构、素材方案与基础验证。

## 推荐方案

采用零依赖 HTML5 Canvas、原生 JavaScript 与 CSS。使用 480×270 逻辑分辨率、像素化缩放及程序化矩形素材，不加载外部图片或音频；普通 `defer` 脚本保证直接打开 HTML 也能运行。

## 实施步骤

1. **页面与视觉框架**
   - 新建 `机甲对战.html`：Canvas、标题、双人按键说明、开始/重开提示。
   - 新建 `样式.css`：深色复古街机界面、响应式居中布局、像素字体回退、`image-rendering: pixelated`。
2. **游戏核心**
   - 新建 `游戏.js`，以 `Game`、`Input`、`Fighter`、`Renderer` 和粒子对象划分职责。
   - 使用固定时间步长更新移动、重力、跳跃、场地边界、角色朝向和简单身体推挤。
   - `Input` 支持双人同时按键，并阻止游戏方向键滚动页面。
3. **战斗与胜负**
   - 双方初始 100 点生命；P1 使用 A/D 移动、W 跳跃、F 攻击、G 防御，P2 使用方向键移动/跳跃、K 攻击、L 防御。
   - 近战攻击包含前摇、活跃帧、后摇和冷却，每次挥击最多命中一次；命中造成伤害、击退、短暂受击和火花。
   - 面向攻击者时防御可大幅减伤，防御期间不能攻击；背后攻击不能被防御。
   - 60 秒回合：生命归零立即失败；超时生命较高者获胜，同血平局；Enter 开始或完整重开。
4. **动画与素材**
   - 以青蓝和橙红区分两台机甲，使用 Canvas 小矩形拼装头、躯干、四肢和武器。
   - 实现待机、跑步、跳跃、三段挥击、防御、受击、倒地状态，以及场景视差、命中火花和微弱屏幕震动。
   - 场景由星空、城市剪影、像素月面/金属擂台构成；所有素材参数集中在绘制函数中，便于后续替换为精灵图。
5. **交付说明**
   - 在页面中直接展示玩法与操作；完成后在回复中说明核心结构、素材替换方式和启动方法，不额外引入依赖或无关文档。

## 验证

- 通过本地静态服务器运行，并检查直接打开 HTML 的兼容性。
- 使用浏览器验证开始、双人同时操作、跳跃与边界、攻击冷却、单次命中、正面/背面防御、击退和重开。
- 验证生命归零、超时分胜负、同血平局，以及结束后不再结算伤害。
- 检查不同窗口尺寸下的像素缩放、按键说明可读性和控制台错误。
